Welcome to my **DSA Practice Hub**! 🚀  
This repository is dedicated to building a strong foundation in **Data Structures and Algorithms (DSA)**. Whether you're preparing for interviews, improving problem-solving skills, or brushing up on core concepts, this repo is the place to be.

## 📚 Topics Covered

### 🧰 Data Structures

| Category              | Description                              |
|-----------------------|------------------------------------------|
| Arrays                | Basics, Sliding Window, Two Pointers     |
| Strings               | Pattern Matching, Manipulations          |
| Linked List           | Singly, Doubly, Cycle Detection          |
| Stack                 | Infix to Postfix, Parenthesis Matching   |
| Queue                 | Circular Queue, Deque                    |
| Hash Map / Set        | Frequency Maps, Hashing                  |
| Trees                 | Binary Trees, BSTs, DFS, BFS             |
| Heaps                 | Min Heap, Max Heap, Priority Queue       |
| Graphs                | DFS, BFS, Topological Sort, Dijkstra     |
| Tries                 | Prefix Trees, Autocomplete               |
| Union Find            | Disjoint Sets, Path Compression          |
| Segment Tree          | Range Queries, Lazy Propagation          |
| Binary Indexed Tree   | Efficient range queries and updates      |
